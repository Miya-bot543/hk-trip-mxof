| Toast | 畫面底部短暫提示 | `toast()` |

## 3. 各章節內容
- **首頁**：封面（電腦 2:1、手機 4:5，`<picture>`）→ 今天卡片 → 天氣 → 旅行摘要（日期、天數、住宿數、主要路線、分批返台、主題快捷按鈕）→ CONTENTS 目錄（圖示＋編號）→ 10 日行程條 → 插畫地圖 → 航班摘要（依兩組分）→ 四間住宿摘要。
- **插畫地圖**（`mapHTML()`）：1448×1086 立體插畫＋SVG 疊層；5 個地名標籤（可點，旁邊面板顯示相關日期、住宿、跳轉）；8 段編號虛線路線（流動動畫，滑雪段金色＝預定）；旅行中「📍 今天」光圈。座標是**插畫像素**，不是經緯度。

- **03 住宿**：住宿時間軸（9 晚色塊可點）；住宿 1 寬卡（兩筆訂房票卡並排）；住宿 2～4 三欄卡；每張有特色小圖、亮點、注意、地圖、🚕司機卡。

## 4. 口袋名單 UI（v2 直接沿用，改接資料層）
這套 UI 原本在「Claude 版」接 Claude 的共用資料庫，已經有完整的新增／修改／刪除；GitHub 版因為沒有資料庫，自動退回唯讀（`STATIC_BUILD`）。**程式碼都還在 `index.html` 裡**，v2 只要把資料來源換成 Supabase。
- 資料欄位（每筆）：`name, cat(spot/shop/food), area, venue(室內/戶外/園區), address, transport[], tags[], info{}, extra[{k,v}], note, done, wantBy{}`。
- 分類專屬欄位 `PK_FIELDS`：景點（開放時間、門票、建議停留、注意事項）、購物（營業時間、公休日、想買的東西）、美食（分店、營業時間、公休日、招牌、預約、候位、預算）。
- 選項常數：`PK_AREAS`（22 個地區）、`PK_TRANSPORT`（14 種交通）、`PK_VENUES`、`PK_CATS`。
- 卡片 `pkCardHTML()`：預設收合（名稱、標籤列「📍地區＋室內戶外＋自訂標籤」、2 行介紹、♡想去／✓已去、看詳細、地圖）；展開後顯示全部欄位與修改／刪除。
- 表單 `pkFormHTML()`／`pkSave()`：分類切換時欄位跟著換、自訂欄位可增刪、標籤逗號分隔。
- 篩選：分類 chip、地區 chip、全部展開／收合。
- 地圖按鈕 `pkQuery()`：有地址用地址，否則名稱＋地區。
- 21 筆資料在 `POCKET_SEED`（已核對：三大蟹年末年始公休警告、閻魔堂時間、諏訪神社御守、おにゃんこ寺等）。
